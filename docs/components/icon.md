## 相关属性

| 属性  | 描述             | 值                                                        | 默认值 |
| ----- | ---------------- | --------------------------------------------------------- | ------ |
| icon  | 使用的图标名称   | 'primary' \| 'success' \| 'warning' \| 'danger' \| 'info' | 必传   |
| type  | 与组件库主题一致 | string                                                    | 无     |
| color | 设置图标色彩     | string                                                    | 无     |
